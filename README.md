# Українська локалізація для reVC (Reverse Engineered GTA: Vice City)

Мета цього проекту: адаптувати український переклад GTA: Vice City від Andrulko до двигуна reVC з підтримкою всіх ОС, на якій працює цей двигун.

Зверніть увагу: ця локалізація призначена для роботи з форком [reVC від AltronMaxX](https://github.com/AltronMaxX/reVC) і вже включена до його складу. З оригінальним рушуєм ця локалізація буде відображатись некоректно, бо в форці додано можливість зміни відступів через конфігураційний файл.

В подальшому я планую розвивати цю адаптацію.

Наразі ця локалізація містить власні правки:
+ Перекладені назви транспортних засобів, оскільки мені здалось, що так гравець буде краще розуміти світ гри
